开场

假设你只有一部手机、没有资源，先做什么？

访谈的起点

不是立刻决定做什么生意，而是先建立一个能帮助自己持续做出更好决定的系统。

01 / 让信息留下来
把自己数字化

把目标、现状、行为和结果逐步保存成文档，让下一次分析能从已有事实开始。

02 / 把决策打开
用 AI 探图

扩大候选范围、比较选择、发现新变化，不急着把人生押在第一个答案上。

03 / 保持能长期玩
养护身体、保留弹性

把健康与选择自由当作长期底盘，而不是等出问题再修。

故事背后的反转多数人会问「有什么行业最赚钱？」；嘉宾的回答更接近「先让自己的认知、工具和行动机制变得更强，然后再从更大的世界里找方向」。这不是某条固定的发财路线。

PART I · 小白理解区 / 把核心问题讲清楚
01

认知、健康、独立判断、AI：四项能力怎么协同？

访谈使用了一套带有个人风格的词汇，翻译成常见语言，其实是四个互补层次。

认知升级：理解现实与选择

对应嘉宾反复谈到的个人成长方法：不是依赖单一理财技巧，而是重新理解目标、选择、价值创造与环境变化。

解决的问题「我究竟在玩什么游戏？什么才是我想要的回报？」

健康管理：长期行动的基础

访谈主要讨论力量训练、日常活动、营养、睡眠与主动健康管理，并非要求每个人从事格斗运动；训练安排应符合个人身体条件。

解决的问题「能否保持体能、精神和长期执行能力？」

独立判断：保持理性与行动力

访谈强调：面对外界评价时，不必因为追求合群而改变有证据支持的选择，也应愿意听取合理批评。

解决的问题「别人不认同，我怎样继续验证自己的方向？」

AI：信息与执行辅助系统

用于记录资料、比较方案、提出建议、辅助日常执行与复盘。嘉宾非常强调把各方面「AI 化」。

解决的问题「信息太多、判断太难，怎样用工具降低成本？」

四者不是平行口号，而是各有分工

认知决定方向
→
AI扩大信息与能力
→
独立判断抵御噪声并校验
→
健康支撑长期行动

嘉宾倾向于让 AI 深度参与决策。本手册保留其重视工具的观点，但不把任何工具当成绝对权威。与后文的 small ego（愿意纠错） 联合起来，更稳妥的实践是：利用 AI 挑战认知，同时让证据和现实结果约束 AI。

原文定位：第 25—49 行；健康与认知的扩展第 109—169、287—311 行。
02

「全部 AI 化」：先把生活变成可读取的信息

访谈里最可复用的一点，是把信息存放在自己能管理的文档中，而不是永远依赖某一次对话。

先理解 AI 化的 5 步

采集现状

把当下的目标、约束、任务、时间、已有资源写下来。不是先问「怎么赚钱」，而是先让问题具体。

建立自己的 Markdown 文件

使用 .md 文本记录，关键内容有固定位置。它轻便、可搜索，也方便不同软件读取。

让 AI 读取与分析

在你已授权、且支持读文件的工具里，把记录交给 AI，让它描述现状、指出信息缺口、提出候选方案。

真人审核并行动

用真实约束检查建议：预算够不够？风险能承受吗？数据对吗？必要时征询相关专业人士。

结果回填，生成复盘

每天或每周记录「原计划—做了什么—结果如何—下次怎么改」。让系统逐渐积累你自己的经验。

访谈里的真实案例嘉宾把饭前饭后的餐食照片、训练动作视频、重量与组数、睡眠设备数据，交给 AI 帮助整理日报；并保留本地文档，以便未来换工具时由另一个 AI 接手。这是记录工作流的示例，不表示 AI 对营养、热量或健康的判断天然准确。

一个小白就能搭的个人资料夹

下面是整理者改写的示例目录，不是嘉宾原样给出的文件名。只用手机记事本或电脑文件夹也能从简开始。

PERSONAL_AI / 便携式资料结构
个人AI系统/
├─ README.md         # 先告诉新 AI：我是谁、文档怎么用
├─ 01_现状与约束.md    # 可支配时间、预算、资源、目标
├─ 02_重要决策.md      # 选择、理由、备选方案
├─ 03_每日记录.md      # 做了什么、发生了什么
├─ 04_行动实验.md      # 假设、试验、结果
└─ 05_每周复盘.md      # 继续 / 调整 / 停止
为什么本地存一份？

便于备份、迁移模型、重复使用，也降低被单个平台或一个聊天窗口锁住的风险。

它不意味着什么？

并不意味着任何 AI 都能自动访问你的文件；具体读取、同步和 API 都受权限、套餐和工具限制。

边界：隐私与健康数据身份证、密码、完整财务流水、医疗记录、他人信息等不应不加筛选地上传到任意模型。应先脱敏，并确认工具的隐私、数据处理和授权规则。
原文定位：个人健身记录与 AI 日报第 5—15 行；低预算、手机、Markdown、本地文件及跨模型使用第 17—49 行。
03

「探图思维」：把做决定从猜测变成比较

这是整场访谈最强的决策类比：打游戏时，不是先在家里拼命造兵，而是先派侦察兵看清资源和局势。

为什么很多人选错？因为地图没打开

未探图
先决定、再找证据

「听说 AI 很赚钱，我立刻做某个项目。」不知道客户是谁，也不知道同类有多少。

已探图
先看选项、再试一个

了解用户需求、竞争者、价格、交付方式、时间成本后，再做最小试验。

「先开地图，再决定往哪里走。」

嘉宾用三个形象化例子说明：看 100 套房再认识行情，比较 100 个专业再认识职业可能性；以及「10 个选项，前几项先建立基准」的数学选择类比。其真正想表达的是：不要因为样本太少就过早锁定答案。

不能机械照搬现实中的房产、工作和项目并不是「错过就不能回头」的标准数学题。「先建立样本基准、再比较新的候选」只是一种帮助思考的类比；样本大小、是否可以回头选择及机会成本都应单独考虑。

把「探图」变成 6 个实际问题

A / NEED
谁有问题？

具体的人群、场景、频次、痛苦程度。

B / CHOICES
现有选择是什么？

至少找到几种替代方案，不限于熟悉的平台。

C / GAP
差距在哪里？

价格、速度、体验、信任、专业知识、语言。

D / LIMITS
有什么限制？

时间、预算、法律条款、交付、资质与风险。

E / TEST
最低成本怎么验证？

做样品、访谈用户、提供试服务，不急着扩大。

F / SIGNAL
什么结果才算有用？

有人真正使用、复购、愿意付费，或成本确实下降。

原文定位：第 79—97 行，关于买房、择业、侦察兵、王者荣耀插眼和打开地图的连续类比。
04

全球机会，不是「全世界都可以卖」这么简单

访谈认为 AI 降低了语言与信息门槛，商机不应只在家门口寻找；真正关键的是能否持续向某类客户创造价值。

从「地域差」找到「价值差」

发现需求谁正在受困
→
找到差距本地供给不足
→
合法连接语言、渠道、交付
→
形成价值用户得到实际改善
访谈中的例子背后的机会逻辑必须补上的验证
中国供应链对接全球用户某地生产优势，可以对接另一个市场的真实需求产品认证、售后、税费、运费、当地法规、信任成本
跨区域服务需求观察不同市场的语言、支付、售后与使用习惯差异先确认服务商授权、当地规定及真实交付条件；不以规避地域限制或转售条款作为商业模式
内容与语言服务用 AI 降低跨语言获取信息、制作内容的成本文化适配、准确性、版权及真实用户反馈
把「创造价值」说具体价值不是你使用了 AI，也不是市场足够大，而是目标用户在支付一定代价之后，确实比原先更省钱、更省时、更安心，或得到原本得不到的结果。
原文定位：全球机会、接口服务与中国制造第 67—79 行；价值创造的相关讨论第 171—179 行。

「碳基服务器」：为什么主动健康管理被放在最底层？

访谈用一个很直观的比喻：人可以指挥越来越多的 AI，但人的身体不能被忽视。

重视日常健康管理，也要按需接受专业诊疗

碳基系统：人

睡眠、身体活动、肌肉力量、心肺健康、饮食和恢复，影响长期活动能力。

硅基协作者：AI

帮助整理记录、回顾趋势、准备就医问题，但不是有执照的诊疗人员。

访谈中的执行样本嘉宾描述了固定训练日、记录力量动作、配合教练拍摄视频、保存餐食图片、佩戴设备追踪睡眠，并用 AI 生成日报的流程。目标是连续观察数月，而非只凭一天判断效果。

可提炼出的健康工作流

→
实施计划训练、活动、休息
→
记录感受持续性与恢复
→
专业复核适当调整

07

「逐水草而居」：财富自由先从选择权开始

嘉宾把游牧民族的「逐水草而居」改写成现代策略：哪里更能发挥价值，就保留去哪里的能力。

为什么访谈反复强调「机动性」？

技术、行业和需求都在变化。一个人越是被固定成本、单一路径或无法转移的工作方式束缚，遇到新机会时越难行动。因此，嘉宾强调地理、职业和资产上的灵活性。

可迁移的东西

技能、作品、经验、文档、远程协作能力、信誉、现金流和人际支持。

需要认真评估的承诺

长期债务、固定支出、搬迁成本、家庭责任、受平台限制的业务。

先自由，后财富；而更多财富也可能扩大进一步的自由。

这是访谈的一个核心飞轮：多一点选择空间 → 更容易尝试机会 → 增加回报 → 有能力争取新的选择空间。但「自由」不只是心理上决定；现实生活中的收入、安全、照护和制度条件同样重要。

不要推成极端结论访谈表达了对长期固定承诺可能影响机动性的担忧；是否购房、置业或组建家庭没有统一答案。家庭也可能提供稳定与支持，应结合实际收入、责任、个人意愿及可逆性综合判断。
原文定位：逐水草而居第 171—189 行；先自由后财富与正负循环第 343—355 行；婚姻问题第 381—397 行。
08

「Small ego」：越有经验，越要保留改正自己的能力

嘉宾认为一个人成功之后，最容易被过去的成功锁住：以为以前对，以后也必然对。

版本更新，不是追逐所有新事物

旧认知原先怎样判断
→
新证据哪些事实冲突
→
更新假设什么需要修正
→
重新验证做法是否更有效

Small ego（低自我执念）在这场访谈中的意思，不是没有自信，而是不把自己的身份、地位或既有判断当成不可被质疑的真理。一个在某领域很强的人，在其他领域仍可能不了解。

嘉宾采用的「三个参照系」

工程 / 创造
科技创业者

观察工程实现、产品研发和跨领域协作。

金融 / 长期
长期经营者

关注持续积累、审慎决策和长期经营能力。

个人品牌 / 跨界
品牌运营者

研究传播表达、个人品牌和跨领域经营。

这三类能力是对嘉宾个人参照对象的抽象归纳，不是对任何具体人物行为或观点的认可，也不代表适合所有人。

真正值得学的一件事可以向不同的人学习某一项可验证的能力，同时不继承他们所有观点。学习方法，而不是崇拜一个完整的人设。
原文定位：认知、ego、版本补丁约第 269—339 行；三个 benchmark、跨界与参照系第 443—473 行。
09

从文本到货币：什么叫「让机器读得懂」？

这是访谈把 AI、数学、区块链和文明记录串在一起的特殊视角。

两个技术话题，一条「可处理」的共同线索

A · KNOWLEDGE
知识数字化

把论文、思想、证明、历史记录转为可以检索、引用、校验和进一步分析的资料。访谈特别谈到数学的形式化证明。

B · PAYMENT
可编程支付

让软件按规则发出支付请求、记账、清算或结算。访谈认为，可编程结算技术可能用于部分软件服务之间的小额交易。

嘉宾用「翻译为机器听得懂的语言」来形容这类转变：原本只在人脑、纸张或传统流程中流动的东西，开始被整理为可供计算机处理的格式。

这两个类比各有自己的技术边界

谈话中的表达实用的理解容易被误解的地方
「不转成数字语料就不存在」记录可以提高传承、检索和复用的机会未上网的经验当然仍存在；隐私和版权不能忽视
「数学证明要形式化」用严格的可机器检查形式表达证明不是所有证明都能简单翻译，也不表示 AI 一定能证明新难题
「数字支付可以被软件处理」部分链上支付具备公开可验证和可编程特征传统电子支付也有数字账本和 API；任何技术方案都不是唯一选择
「AI Agent 可以互相付款」探索自动化服务调用、计费及结算权限、安全、监管、争议处理与成本仍必须设计
投资与技术注意本章仅介绍数字支付与可编程结算的技术讨论，不提供任何资产交易、收益预测或购买渠道。技术可用性不等于投资价值；受访者的个人选择不能作为读者的资产配置依据。

财富自由之后，人到底在追求什么？

访谈后半段由「如何成功」转向「为何继续生活」。嘉宾并未声称自己有唯一答案，而是强调体验与创造。

从「我要达到终点」转向「我还能探索什么」

嘉宾把人生比喻成 Earth Online（地球在线）：人一开始并不知道全部玩法，很多目标也是在实践中逐渐发现。财富或事业既可能是结果，也是开启下一类体验的「门票」。

体验：认识世界

旅行、换角色、学习、创业、研究、与人合作。它们不一定要先证明有宏大意义。

创造：留下新东西

作品、服务、知识、组织、研究、关系中的关怀与培育。创造并不等于赚到最多钱。

未必先找到人生意义，才有资格开始行动。很多意义是在经历中被发现的。

他用诺贝尔、李煜、爱因斯坦、创业者和旅行者等故事强调：一个人的最终影响，未必等于一开始设想的职业目标。方向可以粗一些，体验可以真实一些，结论可以晚一些。

关于爱情与家庭，嘉宾的态度反而比较谨慎

访谈明确谈到：对婚姻和关系的长期规律，他仍在摸索，不能给出成熟答案。他认为金钱无法简单替代感情本身。因而本手册不把「不结婚」或任何单一生活方式写成必选项。

收束到一条主线建立能力，是为了扩大可选择的生活；保留选择，是为了有机会经历和创造。如果一个工具系统最后只剩不停追逐指标，却没有人的体验与判断，就偏离了访谈后半段试图讨论的东西。

4 个可以直接复制的 AI 指令

原则：一段话解决一个问题。先让 AI 区分已知、未知与假设，避免模型把自信语气当作事实。

模板 1 · 建立个人基线

盘点现状 / 第一次使用
你是我的个人分析助手。请先基于我提供的资料建立“现状地图”，不要直接推荐职业或商业赛道。
资料：【粘贴我愿意分享的现状、目标、时间、技能、预算】
请输出：
1. 已确认的事实（只能依据输入）。
2. 尚不清楚、会影响判断的 10 个问题。
3. 我目前能利用的资源和明确限制。
4. 三种不同的行动方向及其各自的代价。
5. 哪些结论必须通过现实行动再验证。
不编造数据，不把推测写成事实；结果用 Markdown 整理。

模板 2 · 探图与候选方案比较

展开选择 / 不急于下注
我的问题是：【要解决的具体问题】。
我的限制是：【预算、时间、地点、技能、风险上限】。
请先“探图”，列出尽可能不同的可行方案，按用户需求、进入门槛、竞争替代、交付成本、合规风险、试错成本和可逆性比较。
请区分：已验证资料、合理推测、需要现场确认的信息。
给出最值得先测试的 3 个方向，以及每个方向用最小成本验证的动作。
不要把推荐理解为保证成功，不要因为某个方向热门就默认可赚钱。

模板 3 · 三种视角交叉质疑

防止自己与模型一起过度自信
下面是我的一个计划：【计划正文】。
请依次以 3 个视角审查：
A. 支持者：它在什么条件下成立？
B. 反对者：最可能错在哪里？有哪些反例？
C. 实践者：用什么便宜、可观察的实验区分 A 和 B？
请列出共同认可的事实、主要分歧、尚需验证的问题。
最后只给一个“下一步最小行动”，并写明停止条件。
若证据不足，请明确说“不知道”。

模板 4 · 每周复盘与版本更新

记录实际变化 / 下轮继续用
这是我本周原定计划、行动记录与结果：【粘贴记录】。
请制作一份一页的 Markdown 周报：
- 本周原计划是什么；实际完成了什么。
- 有哪些可核验的新数据；它们说明了什么、不能说明什么。
- 哪些原先的判断应保留、修正或撤销。
- 哪项活动创造了真实价值；哪项只是忙碌。
- 下周只保留 3 个最高优先事项；每个写清验收标准。
结尾输出“下一位 AI 接手须知”，避免丢失上下文。

机会探图筛选器：先判断要不要测试

独立运行的小工具。给一个候选项目做信息盘点；评分仅表示你已验证的信息是否充分，不代表投资价值或成功概率。

给你的候选机会做一次「五项验证」

0 = 没有证据 / 1 = 只有推测 / 2 = 已经找到可观察或可靠证据。得分不高意味着需要继续探图。

资料成熟度 0 / 10：先收集真实需求和约束，不必急着投入。
使用逻辑这个小工具故意不直接告诉你「做 / 不做」。它先逼你发现哪一类关键信息还没有证据。这比一个看似精确的暴富分数更接近访谈的「先探图」主张。

PART III · 资料与边界 / 保留重点，也保留判断力

观点 ≠ 事实：这 10 类判断需要留白

本手册仅凭访谈文本整理，未做外部事实核查。以下将强烈表达与可稳妥使用的方法分开，避免把受访者的信念写成被证实的事实。

访谈中的说法 / 论证方式为何不能照单全收更稳妥的用法
「把 AI 当成绝对权威」模型会出错、遗漏条件，也可能对未核验信息过度自信用 AI 提意见，但由人核查重大决定
「极短时间完成世界级科研突破」的个别叙述转录没有给出可核对的正式论文与证据链如无正式来源和可复核证据，不作新闻事实传播
「数据量就是智商 / 信息越多就越聪明」这是过度简化的类比，不能独立解释人类或模型能力保留「持续学习和校验」的实践启发
「把身体状况折算成固定分数」没有提供通用医学评分依据重视健康，但不使用这个分值替代风险评估
「单一训练方式足以覆盖全部健康需求」不同运动适应不同；不能从个别训练经验推成所有人的规则依据体能基础和专业指导安排活动
「锻炼能保证某个年龄的健康结果」健康结果受疾病、环境、伤害及多个因素影响将运动理解为长期风险管理，而非保证书
「某一种支付技术是机器交易的唯一方案」传统银行和电子支付同样有机器接口与数字账本比较不同支付架构的真实优势与限制
「新技术 / 新资产一定带来更高回报」新技术不保证适用性，更不保证投资收益看用途、成本、风险和真实反馈
「赚钱越多说明对社会越有价值」价格反馈不能完整衡量公共利益与长期影响收入可作为商业反馈之一，但不是唯一标准
「没有数字记录的内容就毫无价值」未数字化的历史、经验与人与人的关系仍然真实存在重视可传承记录，同时尊重隐私、版权与授权
同样需要警惕的推断「长期家庭承诺必然拖累发展」「信息传播越分散就一定越真实」「所有年轻人都应选择同一个赛道」等，都是范围过大的判断。案例可以帮助理解，但不能替代对不同人的条件、风险和事实的检查。

档案 4 · 为什么他反复用「版本」「北极星」「体验」来解释人生？

三个外部标尺

分别观察科技研发、长期经营与跨界品牌三类能力；强调跨领域取长补短，而不是照搬某位人物的完整路线。

长期投入的愿望

嘉宾以超长时间跨度设想个人事业，表达持续学习和拓展边界的愿望；它不构成寿命预测或成功承诺。

重新体验其他视角

已在创业的人仍希望了解「作为员工」的公司经验；他用模拟经营游戏、旅行和太空体验说明不同视角的价值。
